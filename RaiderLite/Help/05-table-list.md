# Finding tables

The **Tables** tab of the left panel lists each open image, its table categories, and the tables
in each category.

## The table list

- Click a table to open its window, and click it again to close it. **Enter** opens the selected
  table. You can make this a double-click instead in [Settings](settings).
- A table shown in **bold** has changed since the image was opened. An image with unsaved
  changes has a `*` before its name.
- The icon beside a table shows its kind: a single value, a row of values (an array or a curve),
  a map, or a switch.
- Tables above your user level are shown in grey (see the View menu below).
- Hover over a table to see its shape, its address and its description.
- Right-click an image for Save, Save As, Close, Properties and the tune library commands.
  Right-click a table to open it or see its properties.

## Filtering

To show only the tables whose names contain some text, type it in the box above the list, or
press **Ctrl+F** to go there first. **Esc** clears the filter, and **Down** moves into the list.

## The View menu

| Command | What it does |
|---|---|
| **User Level** | Sets which tables you can edit, from 1 (Beginner) to 5 (Debug). The definition gives each table a level, and tables above yours are read-only. |
| **Display High Level Tables** | Sets whether tables above your user level are listed at all. |
| **Sort Tables Alphabetically** | Sorts the tables in each category by name instead of in definition order. |
| **Expand All** / **Collapse All** | Opens or closes every category. |
| **Find Table** (Ctrl+F) | Moves to the filter box. |
| **Tunes** / **Tables** | Switches the left panel's tab. |

## Table properties

To see a table's properties, right-click it and choose **Properties**, or choose **Table > Table
Properties** in its window. They include its category, type, shape, storage address and type,
byte order, size and layout, mask, user level and description.
