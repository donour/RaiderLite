# Keyboard shortcuts

## In a table

| Keys | Action |
|---|---|
| Type a number | Start entering a value. **Enter** sets the selected cells to it, **Ctrl+Enter** multiplies them by it, **Esc** cancels. |
| **+** or Ctrl+Up | Increase by the coarse step |
| **_** or Ctrl+Down | Decrease by the coarse step |
| **]**, Ctrl+Shift+Up or Ctrl+= | Increase by the fine step |
| **\[**, Ctrl+Shift+Down or Ctrl+- | Decrease by the fine step |
| **\*** or Ctrl+Enter | Multiply the selected cells by the value box |
| Shift+I | Interpolate |
| Shift+V | Interpolate vertically |
| Shift+H | Interpolate horizontally |
| Ctrl+C or Ctrl+Insert | Copy the selection |
| Ctrl+V or Shift+Insert | Paste |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+A | Select every cell (click the top-left corner of a map for the data only) |
| Ctrl+G | Show or hide the graph (curves and maps) |
| Esc | Close the table window |

## In a single-value window

| Keys | Action |
|---|---|
| Enter / Esc | Set the typed value / cancel it |
| Up / Down | Increase / decrease by the fine step |
| Shift+Up / Shift+Down, Page Up / Page Down | Increase / decrease by the coarse step |
| Ctrl+Z / Ctrl+Y | Undo / redo (while typing, Ctrl+Z undoes the typing) |

## In the main window

| Keys | Action |
|---|---|
| Ctrl+O | Open an image |
| Ctrl+S | Save the image |
| Ctrl+Shift+S | Save the image under a new name |
| Ctrl+Shift+N | New revision |
| Ctrl+F | Filter the tables |
| Enter (in the table list) | Open the selected table |
| Enter (in the timeline) | Open the selected revision |
| Delete (in the timeline) | Delete the selected revisions |
| Esc (in a filter box) | Clear the filter |
| F1 | Help on what you're doing (also in table windows and dialogs) |

## In the help

| Keys | Action |
|---|---|
| Alt+Left / Alt+Right | Back / forward |
| Ctrl+F | Search the help |
| Esc | Clear the search, or close the help |
